# 서바이벌 v0.8 — 모바일 단일 화면 · 플로팅 미니맵 · 상황 아이콘

## 목표
서바이벌 플레이 중 휴대폰 세로 화면에서 스크롤하지 않고 이동·질주·숨기와 지도 확인을 끝내도록 구성한다. 기존 3개 월드 지형·적·자동 은신·열쇠·탈출 로직은 그대로 유지한다.

## UI
- **게임을 시작한 경우에만** #gameScreen 및 페이지를 `position:fixed; height:100dvh; overflow:hidden`로 잠금. 설정/월드 선택 화면은 필요할 때 정상 스크롤 가능.
- 플레이 캔버스가 브라우저 사용 가능 화면을 채우도록 `object-fit:cover` 사용. 가로/세로 가장자리에서 화면이 잘릴 수 있으므로 논리 카메라를 실제 표시 비율에 맞게 확장하여 주인공이 월드 좌우 끝에서 사라지지 않도록 함.
- 상황 아이콘 8개를 게임 화면 좌상단 두 줄에 반투명 배치: ❤️ 목숨 / ⏱ 남은 시간 / 🔑·🚪 목표 거리 / ⭐ 별 / 🌴❄️🏺 현재 월드 / 🔒·🔓 열쇠 / 🌿·🙈 은신처·남은 은신 시간 / 👹·🚨 적 위험.
- ⏸ 일시정지 및 ⌂ 게임포털 복귀를 우상단 아이콘으로 배치. 일시정지·재개 후에도 긴 글자가 표시되지 않도록 안전한 고정 DOM 표시.
- 🗺️ 미니맵을 게임 위 우측의 48px 플로팅 아이콘으로 이동. 누르면 지도가 확장되고 다시 누르면 닫힘. 별도 캔버스이므로 **접힌 상태에서 탈출 게이트나 캐릭터를 덮지 않음**.
- 방향키·긴급 질주·숨기/나오기는 게임 아래쪽에 안전영역만큼 띄워 플로팅, 재시작은 작은 ↻ 아이콘. 모바일 세로·가로의 작은 뷰포트에서 폰트·버튼 크기를 조정.
- PC/키보드에서는 기존 자세한 HUD 및 게임 레이아웃 그대로 사용하고 미니맵은 자동으로 열림.
- 민감정보 저장·추적·외부 이미지·신규 의존성 없음.
