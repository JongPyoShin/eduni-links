# 의준 서바이벌 v0.5 — 2.5D 정글 아트 전환

## 방향
- 현재 EDUNI **정글탐험 3D**의 둥근 얼굴·파란 탐험가 모자·가방·나무 숲·부드러운 자연색 등을 참고한다.
- 그러나 서바이벌은 기존 2048×1536 2D 충돌/경로/카메라 게임을 보존하기 위해, **Canvas 2D 레이어 기반 2.5D**로 구현한다. Babylon 3D 엔진을 가져오거나 카메라의 원근을 바꾸지는 않는다.
- 2D 평면 원/이모지 대신 부피·높이·명암이 있는 입체형 벡터 그림을 보여준다.
- 외부 CDN, 동적 이미지, 계정/추적/광고 또는 신규 패키지 없음.

## 구현
- 신규 `portal_app/survival_static/render25d.js`: 순수 도형/그라디언트 엔진.
- **탐험가**: 파란 탐험모자/챙, 머리·볼·눈, 남방, 하의, 부츠, 가방·나침반, 발 그림자, 상하좌우 보이는 방향 구분. 이동 애니메이션·질주·무적 효과.
- **토끼**: 귀와 색상이 다른 입체형 캐릭터, 위와 같은 발 움직임/그림자.
- **원숭이·뱀·재규어**: 꼬리/사지·얼굴·얼룩 등 동물별 고유 형상, 속도 기반 가벼운 모션. 더는 동물 이모지로 표시하지 않는다.
- **쉼터**: 굵은 입체 덤불, 속이 빈 나무통, 어두운 동굴 입구. 숨은 중에는 캐릭터를 그리지 않고 쉼터 뒤에 숨으며, 은신 초는 HUD에 표시한다.
- **나무**: 충돌 영역과 일치하는 지면 흔적, 여러 나무줄기, 윗잎 덮개와 그림자. `y`값/발 위치 기준으로 나무·동물·플레이어·아이템 렌더 순서를 정한다. 화면상 뒤쪽 캐릭터가 나뭇잎 뒤에 자연스럽게 가려진다.
- **랜드마크**: 텐트/나비/꽃밭/돌 유적/폭포를 단순 이모지 대신 부피감 있는 도형으로 표현한다.
- **아이템/출구**: 입체 황금열쇠·별·돌문과 보호/위험 영역도 렌더러에서 그린다.
- **선택 화면**: 실제 게임 캐릭터 모습을 Canvas 미리보기로 제공한다.
- HTML은 NiceGUI 서버 및 Pages 모두 새 `render25d.js?v=5`를 `game.js`보다 먼저 불러온다. 포털 카드 문구도 버전과 맞춘다.

## 게임 로직 무변경
- 2048×1536 월드, 720×720 화면·이동 카메라, 8개 쉼터 자동 은신과 단회 소멸, 몬스터 분산 및 재추격, 열쇠·출구·목숨·타이머·별·과일 위험/재시작 규칙은 그대로 둔다.
- 충돌좌표는 기존 게임 로직을 사용한다. 렌더 좌표는 캐릭터의 **발**을 기준으로 위쪽으로 몸체를 그린다.

## 검증 수행
- 기존 게임 논리 **22개 PASS**, 신규 2.5D 그래픽 검증 **4개 PASS**, 모두 격리 V8 JS 평가 (Node CLI를 직접 실행한 것은 아님).
- 독립 Canvas 모의렌더에서 상하좌우 탐험가·토끼, 몬스터 4종, 쉼터 8개/은신 상태, 나무 장애물 14개, 6종 랜드마크, 열쇠/출구/위험 오브젝트 렌더 예외 없음.
- 모의 DOM/Canvas 게임 실제 루프: 선택 화면 프리뷰, 화면 내 2.5D 객체 렌더 호출, 오른쪽 이동/애니메이션, 은신처 자동 진입/은신처 소모, 일시정지, 열쇠→재규어→탈출 승리, 재시작 **PASS**.
- 정적 Pages HTML과 NiceGUI HTML은 내비게이션·스크립트 상대경로 외에 일치하고, 버전 캐시 인자 `?v=5` 사용.
- 신규 URL `/survival-static/render25d.js`는 기존 정적 디렉터리 마운트에 포함되며, 관련 Python 경로 테스트에 검증 추가.
- **미수행:** 실제 Chrome/Android 성능·시각 점검, Node CLI/Jest 전체, Python 전체 단위/콘텐츠 검사, GitHub Pages 배포 확인.
