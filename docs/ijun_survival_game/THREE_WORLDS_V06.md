# 의준 서바이벌 v0.6 — 정글·북극·피라미드 3개 월드

## 목적
v0.5의 2.5D 정글 생존 게임에 **북극과 피라미드**를 추가하고, 시작 화면의 월드 선택으로 분리한다. 외부 라이브러리·광고·추적·개인정보 수집 없이 가족용 브라우저 게임 그대로 운영한다.

## 게임 공통
- 월드 2048×1536, 720×720 따라오는 카메라, 실시간 추격 AI, 발 위치 기준 2.5D 렌더 정렬
- 적 3마리와 열쇠 획득 후 추가 추격하는 보스 1마리
- **쉼터 8곳**: 안으로 이동하면 즉시 자동 은신(4/5/6초), 적들은 멀리 수색, 사용한 쉼터는 사라짐, 종료 후 2.8초 추가 분산 수색 및 잠깐 무적/이속 상승
- 별 5개, 재사용 방지, 스릴 105초/여유 180초, 목숨 1~35, 이동/질주, 일시정지, 열쇠/탈출
- 포털 페이지와 GitHub Pages에서 동일한 HTML 및 버전 `?v=6` 스크립트
- 기존 정글 v0.5 동작과 다른 게임 경로를 변경하지 않는다.

## 월드별 차이
| 월드 | 지역 | 일반 추격자 | 열쇠 획득 후 보스 | 쉼터 |
|---|---|---|---|---|
| 정글 | 이끼길·나비 숲·폭포·고대 유적 | 원숭이·뱀·원숭이 | 재규어 | 덤불·통나무·동굴 |
| 북극 | 극지기지·눈보라 평원·얼음 호수·오로라 빙하 | 북극여우·북극늑대·바다표범 도둑 | 북극곰 | 눈더미·이글루·빙하 동굴 |
| 피라미드 | 사막 캠프·모래언덕·스핑크스 광장·파라오 유적 | 스카라베·미라·아누비스 수호병 | 파라오의 혼령 | 거대 항아리·석관·비밀 벽 틈 |

북극의 장애물은 얼음기둥·빙벽으로, 위험 지점은 고드름/얼음 균열 느낌으로 표현한다. 피라미드 장애물은 사암 석조물·회랑으로, 위험 지점은 돌 함정으로 표현한다. 2.5D 스프라이트는 Canvas 벡터 도형과 그라디언트로 직접 그리며 외부 에셋이 필요 없다.

## 변경 위치
- `portal_app/survival_static/worlds.js`: 공통 게임용 월드 구성·좌표 데이터와 조회 API.
- `portal_app/survival_static/worldart25d.js`: 북극/피라미드 전용 지형·악당·쉼터·보스·출구·함정 렌더.
- `portal_app/survival_static/logic.js`: 장애물·출구·탐색 좌표를 현재 월드 기준으로 받도록 인자 확장. 기존 인자 없는 동작 유지.
- `portal_app/survival_static/game.js`: 월드 선택 및 상태 전달, 몬스터 경로탐색·충돌·지역·미니맵·UI 월드 연결.
- `portal_app/static_games/eduni_survival.html`, `survival/index.html`: 월드 선택 버튼과 안내, 캐시/로딩 순서.
- `portal_app/routes.py`: 포털 설명 갱신.
- `tests/test_survival_worlds.cjs`: 월드 좌표/경로/캐릭터/렌더 관련 9개 추가.
- `tests/test_survival_beta_routes.py`: 신규 정적 리소스 가용 경로 확인 항목 추가.

## 검증
- JS 기존 규칙 **22 PASS** + 2.5D 그래픽 **4 PASS** + 월드 **9 PASS** = **35 PASS** (격리 V8 JS 실행)
- 모든 월드: 시작/열쇠/출구·보스·쉼터·별 좌표가 이동 가능, 시작→열쇠→출구 경로 존재, 8곳에서 4마리의 먼 수색 목적지 확인, 보스 장애물 통과 차단 확인
- DOM/Canvas 모의 브라우저 게임 루프: 정글·북극·피라미드 각각 **시작→자동 은신→소멸→열쇠→테마 보스→탈출 성공** PASS
- 새 그래픽에서 빙벽·사막 석조물·월드별 쉼터·동물 스프라이트·함정·출구 렌더 오류 없음
- HTML 동등성, 스크립트 순서, 정적 경로 검사 문구, whitespace PASS

## 미검증 / 배포
- 실제 모바일 Chrome/Android 성능·터치, 실제 Python 단위/콘텐츠 검사 및 전체 Node CLI, 실제 서버/배포 HTTP 응답은 미검증
- 사용자의 별도 배포 지시 전까지 **Draft PR로 유지**하고 `main` 병합·GitHub Pages 배포를 하지 않는다.


## 게임포털로 진입 이동
- GitHub Pages 진입: `/eduni-links/games/` — 새 `games/index.html`에서 서바이벌·한자 슈터·버블·의준 링크·AI 오목 등 게임 선택
- `/eduni-links/` 메인 화면은 기존 서바이벌 단독 카드 대신 **게임포털** 카드를 표시
- 가족 서버 진입: `/portal/games` — 새 게임포털 전용 NiceGUI 페이지에서 서바이벌 3개 월드와 기존 게임 선택
- `/portal` 빠른 시작에서 개별 게임 카드들을 전용 게임포털 진입 카드로 묶음
- 서바이벌 내부 **← 게임포털** 링크가 가족 서버 및 GitHub Pages에서 각각 해당 게임포털로 복귀
- 기존 `/survival`, `/survival/`, Pages `/survival/`, `/jungle`, `/bubble`, `/bubble-shooter`, `/link`, `/omok` 는 그대로 동작하도록 원래 라우트 및 파일 유지
- 가족 서버는 별도 git pull/서버 재시작이 필요하며, **Pages의 정상 배포가 NiceGUI 서버 자동 업데이트를 의미하지는 않음**
