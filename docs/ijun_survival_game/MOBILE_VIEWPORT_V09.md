# 서바이벌 v0.9 — 모바일 게임 화면 배율 및 조작 UI 보정

## 실제 문제 증거
사용자가 2026-10-12 공유한 Android 브라우저 캡처에서 정글 주인공·지형이 과도하게 확대되고, 펼친 미니맵이 게임 중앙을 크게 가려 플레이를 방해했다.

## 원인
v0.8은 720×720 내부 게임 캔버스를 세로로 긴 모바일 화면 전체에 CSS `object-fit:cover`로 확대 표시했다. 정사각형 소스의 좌우 상당 부분이 잘리고 캐릭터가 과도하게 커졌다. 확대형 미니맵 폭은 최대 342px로, 일반적인 모바일 화면 폭의 대부분을 점유했다. 방향키 또한 플레이 필드 위에 오버레이로 배치되었다.

## 개선
1. **실제 화면 크기에 맞는 논리 렌더링 영역**: 플레이필드의 `clientWidth/clientHeight`로 논리 Canvas 크기를 설정. 세로 화면은 논리 높이 최대 1300, 가로 화면은 논리 너비 최대 1120, 월드 최대폭/높이는 2048×1536으로 제한. `object-fit:fill`은 CSS·논리 비율을 일치시켜 사실상 왜곡 없이 표시. 프레임당 변화 감지 및 첫 화면 표시 이후 초기화.
2. **카메라·맵 축소**: 카메라 범위, 화면 가시성 검사, 배경 질감 드로잉, 미니맵 카메라 사각형을 신규 논리 뷰포트 크기로 연동. 기존 AI, 자동 은신, HP, 별, 열쇠·출구, 적 위치는 그대로 보존.
3. **게임 전용 조작 도크**: 화면 하단 `clamp(108px,19dvh,142px)`를 방향키·질주·숨기·재시작용으로 분리해 주인공·아이템을 가리지 않도록 함. 제스처 안전 영역 패딩 유지.
4. **작은 플로팅 미니맵**: 펼친 지도의 최대폭을 `min(156px,42vw)`로 제한. 지도 제목·범례를 모바일에서 숨기고 아이콘만 표시. 닫힌 지도 버튼도 40px로 축소.
5. **축약 HUD**: 화면 상단 상태 아이콘 높이 28px→22px, 패딩·간격 축소. PC는 기존 디스플레이 유지.

## 모바일 스케일 사례
[Phaser Scale Manager](https://docs.phaser.io/phaser/concepts/scale-manager)의 FIT/RESIZE/ENVELOP(잘림) 비교, [Unity Safe Area](https://docs.unity.com/en-us/engine/7000.0/script-reference/unityengine/screen/safearea)의 휴대폰 시스템 영역 보호 원칙 참조. 복잡한 앱 UI를 그대로 따라하지 않고, 한 화면에 지형과 조작이 모두 나타나는 모바일 액션 게임 패턴을 적용.

- **미검증**: 실제 Android Chrome 시각·FPS·터치 실측, Python 전체 suite, 가족 PC 운영 배포.
