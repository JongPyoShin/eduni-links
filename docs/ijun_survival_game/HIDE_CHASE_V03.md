# 마주치지 마! v0.3 — 계속 추격·시간제 은신처 개발 결과

상태: **개발 브랜치의 플레이 가능한 베타**, `main` 병합 및 배포 전. 작성일 2026-10-11.

## 의준이의 새 요구사항
- 악당들은 게임 시작부터 주인공을 계속 쫓아온다.
- 주인공은 정글 곳곳에 숨을 수 있다.
- 은신처마다 숨을 수 있는 시간이 정해져 있다.
- 은신 시간이 끝나면 사용한 장소는 사라지며, 다시 추격전이 시작된다.

## v0.3 구현

- 기존 원숭이 2마리·뱀 1마리 모두 첫 프레임부터 플레이어를 추격. 기존 정글 장애물을 피해 24px BFS 길찾기 사용. 성능 보호를 위해 악당별 약 0.7초마다 경로 재계산.
- 기존 🔑 열쇠, 출구, 열쇠 획득 후 등장하는 🐆 재규어, 별, 질주, 피격 -1, **1~35개 목숨**, 스릴 45초/여유 90초 유지.
- 은신처 4개: **덤불 4초 × 2곳, 통나무 5초 × 1곳, 동굴 6초 × 1곳**.
- PC: 방향키/WASD 이동, E 숨기/일찍 나오기, 스페이스·Shift 긴급 질주. 모바일: 방향 버튼, 은신처 근처에서 활성화되는 🙈 숨기 버튼.
- 은신 중: 이동/질주 불가, 적과 위험 지점의 피해 무시, UI와 지도에 소수점 남은 시간 표시. 악당은 숨은 곳을 실시간 투시하지 않고 마지막 목격 장소 주변을 탐색.
- 은신 시간이 0이 되거나 플레이어가 먼저 나가면 장소 **1회 소모 후 즉시 삭제**. 이후 같은 장소에 재진입 불가. 추격 재개, 플레이어는 **1.3초 피격 보호 + 0.8초 이동 속도 보너스**로 공정한 탈출 기회.
- 일시정지/백그라운드에서는 은신 타이머와 모든 적·게임 타이머가 함께 정지. 재시작 시 모든 은신처 복구. 기록·아동 정보 업로드 없음.
- 원래 게임과 기존 포털 경로는 수정하지 않고 게임 전용 룰/런타임/HTML만 수정.

## 검증 결과
- JS 순수 룰 테스트: 기존 12개 + 은신처 5개 = **17 케이스 통과(V8 실행환경에서 수행)**.
- DOM·Canvas 모의 플레이: 시작부터 적 추격 → 은신 진입 → 피격 차단/움직임 정지 → 은신 타이머 중지(일시정지) → 시간 종료/은신처 소멸 → 같은 장소 재사용 차단 → 다른 장소 사용/조기 퇴장 → 재시작 복구 → 열쇠/재규어/승리 흐름 **PASS**.
- 신규 정적 Pages와 NiceGUI용 페이지는 동일 UI, 스크립트 캐시 버전 `?v=3`으로 분리 확인.
- **미검증**: 실제 Node CLI/Python 전체 회귀, 실제 브라우저·모바일 기기, 가족 PC 서버 동작 및 GitHub Pages 실제 접근.
- 브랜치에서 변경은 완료했으나 **사용자가 출시를 별도로 지시하기 전 `main` 병합·게시·가족 PC 재시작은 하지 않는다.**

## 인수 시나리오
1. 캐릭터·목숨(1과 35 포함) 선택 후 시작. 열쇠가 없어도 원숭이/뱀이 쫓아오는지.
2. 은신처에 다가가면 🙈 버튼 활성, 밖에서는 비활성. E키도 동일하게 동작하는지.
3. 덤불에서 숨은 채 악당이 겹쳐도 피격되지 않는지, 4초가 지나면 덤불이 시각적으로 사라지는지.
4. 사용한 덤불을 재방문해도 다시 숨을 수 없는지. 다른 통나무(5초)/동굴(6초)는 이용 가능한지.
5. 타이머 도중 ESC/일시정지 시 은신·게임 타이머가 멈추고 재개 후 계속되는지.
6. 숨기 종료 직후 1.3초 무적, 0.8초 가속이 발동하고 적 추적이 재개되는지.
7. 열쇠/재규어/출구, 충돌 목숨 차감, 질주, 제한시간 승패와 재시작이 예전처럼 동작하는지.
8. 휴대폰 세로화면에서 숨기/질주/방향키가 가려지지 않고 눌리는지.
