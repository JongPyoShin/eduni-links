# 마주치지 마! 서바이벌 대모험 — 게임 기획 초안 v0.1

> 제안자: 의준 (종이 손글씨 규칙 설명서, 2026-10-11)
> 상태: 아이디어 구체화 / **미구현·미배포**. 최종 게임명과 플레이 방식은 아이 의견 반영 후 확정.
> 대상: EDUNI Portal의 가족용 모바일·PC 게임. 기존 `/jungle`과는 **다른 독립 게임**.

## 1. 원안: 아이가 직접 적은 6가지 규칙

1. 목숨을 몇 개 할지 고른다. **1~35개** 선택 가능.
2. 어떤 캐릭터를 할지 고른다.
3. 캐릭터를 다 정하면 게임이 시작된다.
4. 정글·사막·북극·화산 중 한 곳을 정한다. (손글씨의 세부 문장은 최종 확인 필요)
5. 게임을 시작하면 누군가와 마주치면 안 된다. 마주치면 목숨 한 개가 사라진다.
6. 끝날 때까지 마주치지 않고 살아남는다.

**반드시 보존:** 플레이어가 직접 정하는 1~35개 목숨, 캐릭터 선택, 정글/사막/북극/화산 4맵, 적과 닿으면 목숨 -1, 마지막까지 생존.

## 2. 핵심 게임 경험

- **한 줄 설명:** 네 가지 신비한 세계를 탐험하며 돌아다니는 적과 환경 위험을 피하고 출구까지 무사히 도착한다.
- **목표:** 각 맵의 출구까지 이동하고, 0 목숨이 되기 전에 완주한다. 가이드 목표 플레이 타임 60~90초(튜닝 가능).
- **순서:** 목숨 선택 → 캐릭터 선택 → 맵 선택 → 시작 → 생존/탈출 → 결과. (원안의 '게임 시작 후 맵 선택'은 실제 UX에서 시작 전 설정 화면으로 통합)
- **화면:** 아이가 알아볼 수 있는 큼직한 캐릭터, 위험을 예고하는 표시, 잔여 목숨 숫자, 현재 위치/진행률, 일시정지.
- **조작:** PC 방향키/WASD, 모바일 화면 D패드 또는 가상 조이스틱. 탭·키보드 동등 지원, 새로고침 시 안전하게 초기화.
- **실패 경험:** 목숨 소진 시 부드러운 '다시 도전' 안내, 미리보기/재도전 제공. 공격·폭력·공포 연출 제외.

## 3. 네 가지 맵

| 맵 | 움직이는 적 | 환경 위험 | 시각적 힌트 |
|---|---|---|---|
| 정글 | 원숭이, 뱀 | 나무 뒤 매복·덩굴 | 나뭇잎 흔들림 |
| 사막 | 전갈 | 모래폭풍·느려지는 모래 | 모래 바람 선 |
| 북극 | 북극곰 | 빙판 미끄러짐·눈보라 | 바닥 반짝임 |
| 화산 | 바위 몬스터 | 굴러오는 돌·용암 분출 | 위험 지점 붉은 예고 표시 |

- 맵은 외형만 바뀌는 '스킨'이 아니어야 한다. 적 이동 방식 + 환경 기믹 최소 1개씩 차별화.
- 모든 위험은 사전 경고 표시와 안전한 회피 경로를 제공한다. 끊임없는 무작위 충돌·출구 봉쇄 금지.

## 4. 캐릭터

초기 후보: 탐험가 / 토끼 / 거북이 / 여우. 첫 버전에서 캐릭터 성능은 동일하게 하거나 장점과 단점을 균형 조정한다. 캐릭터의 이름·외형·능력은 의준이가 최종 결정하는 참여 영역으로 남긴다.

## 5. 목숨과 점수

- **목숨 1~35 고정 선택**: 원안의 가장 독특한 기능이므로 축소하지 않는다. HUD는 ❤️ × 25처럼 숫자로 표시해 가독성을 확보한다.
- 충돌 시 목숨 **정확히 1 차감**, 일시적으로 **1.5초 무적**으로 연속 충돌 방지; 충돌 효과는 친근하게.
- 시작 목숨별 보상 **가안**: 1~3 = 3배, 4~7 = 2배, 8~15 = 1.5배, 16~35 = 1배. 테스트 후 조정.
- 맵 완주 점수 + 남은 목숨 보너스 + 아이템 보너스. 점수는 가족용 개인 기록만; 온라인 순위/프로필/외부 업로드 없음.
- 강화 아이템 후보: 1회 보호 방패, 이동 속도 신발, 하트 회복(초기 선택 목숨 초과 금지). 선택사항이며 '피하기'가 주 플레이를 유지해야 한다.

## 6. 구현 위치와 기존 서비스 보호

저장소: `JongPyoShin/eduni-links`.

- 실제 서버 포털: `nice-gui-1-1-7/portal_app/routes.py` 의 `/portal`.
- 이미 운영 중인 정글 새탐험: `/jungle`. **수정하거나 경로를 재사용하지 않는다.**
- **신규 경로 가안:** `/survival` 및 `/survival/`.
- 독립 정적 Canvas 게임 가안: `nice-gui-1-1-7/portal_app/static_games/eduni_survival.html` (필요하면 JS/CSS 별도 분리), NiceGUI/FastAPI는 HTML 응답 라우팅 담당.
- 포털 `빠른 시작` 카드에 신규 게임 1개만 추가. 기존 한자·오목·링크·버블·블록퍼즐 경로 불변.
- 비밀정보, 트래킹, 광고, 계정 생성, 채팅, 카메라·마이크·위치·아동 정보 업로드 없음.
- 기존 `jungle-web-canvas-poc/`는 정글 캠프 2.5D 별도 PoC다. 자산/물리 로직을 참고하되 기존 PoC를 덮어쓰거나 결합하지 않는다.

## 7. 단계별 출시

### 0단계: 게임 방식을 한 번 정하기 (보류 중)

**결정 필요:** 화면 방식
- A. **탑다운 2D 자유 이동:** 위에서 보는 미로/맵을 자유롭게 움직이며 적을 피한다. 모바일 조작과 4개 맵 구현이 쉽다. **권장**
- B. **2.5D 횡/세로 탐험:** 캐릭터 뒤/비스듬한 시점에서 길을 따라 움직인다. 시각적으로 풍부하지만 구현/충돌/모바일 최적화 비용 높음.

### 1단계: 첫 플레이 가능 버전 (Beta)

- 캐릭터 2종, 1~35개 목숨 선택, 정글 1맵, 서로 다른 2종 적, 출구·승패, 재시작·일시정지, PC/터치 조작.
- 충돌 처리 1회 차감과 무적 시간, 무리한 난이도 발생 여부 확인.
- **정글 1개뿐일 때는 다른 3맵을 완성된 것처럼 버튼에 노출하지 않는다.** 개발판임을 표시한다.
- 베타는 실제 서버 포털에 공개 전, 독립 주소에서 가정 테스트.

### 2단계: 4맵 완성 (v1)

- 사막/북극/화산 추가, 맵별 위험 패턴, 캐릭터 4종, 아이템 2종, 결과 화면과 로컬 기록.
- 포털 빠른 시작 카드 및 경로 추가, 서버 시작·라우팅 정상 동작 확인.
- 한자/학습 문제 **강제 삽입 금지**: 아이가 구상한 회피 액션이 중심. 교육 연계는 향후 선택적 요소로만 검토.

## 8. 출시 체크

- 1과 35 모두 정확히 목숨 차감/게임 종료 처리. 0 이하 음수·중복 차감 없음.
- 모든 맵에 도달 가능한 출구, 한 번에 피할 수 없는 적 배치 없음.
- 모바일 세로/가로 및 PC 해상도에서 플레이 버튼/조작 UI가 화면 밖으로 나가지 않음.
- 키보드와 터치 입력 동시 지원, 일시정지 중 적 움직임과 타이머 정지.
- 처음 보는 7세 아이가 별도 설명 없이 시작·재시작 가능.
- 기존 `/`, `/bubble`, `/bubble-shooter`, `/jungle`, `/link`, `/omok`, `/portal` 기존 기능 영향 없음.
- 리포지토리 `AGENTS.md`의 제한, 검증 및 깃 브랜치 격리 원칙 준수. 승인 없이 main 병합/배포 금지.

## 9. 아이와 함께 확정할 질문

- **화면을 위에서 내려다보며 움직이는 게임(A)으로 할까, 입체적으로 탐험하는 게임(B)으로 할까?**
- 캐릭터의 실제 이름과 그림은 무엇으로 할까?
- '마주치면 안 되는 상대'는 어떤 동물/몬스터인가?
- 탈출 성공 조건은 마지막까지 버티는 시간, 출구 도달, 혹은 둘 다인가?

이 문서는 아이의 원안을 보존하는 개발 출발점이며, 아직 구현이 완료되었다는 의미가 아니다.
