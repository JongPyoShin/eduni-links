# EDUNI 소리톡 파닉스 — 영어 음가·단어 발음·따라 읽기

## 개요
가족 학습 포털의 '영어' 준비 중 카드를 신규 **소리톡 파닉스** 페이지로 연결한다.

- 가족 포털 페이지: `/portal/english/phonics`
- HTTPS 미리보기: `https://jongpyoshin.github.io/eduni-links/phonics/`
- EDUNI Portal 빠른 시작 및 학습 세계의 영어 카드, 상단 바로가기에서 이동
- 개인 맞춤 프로필·녹음 파일·음성 인식 문장·학습 결과를 EDUNI 서버에 **저장하지 않음**

## 단계와 활동
1. 1단계: 연속음이 포함된 규칙적인 CVC 12단어 (sun, man, fan, fin, run 등)
2. 2단계: 추가 CVC 단어 및 첫 복합자음(digraph) 12단어 (cat, ship, fish, chip, thin 등)
3. 각 단어는 표기 단위와 단일 음가(IPA)를 미리 검증한 목록으로 관리. 자동 글자→소리 규칙을 생성하지 않음.
4. 각 음가 카드 터치: 브라우저에서 지원하는 **합성 참고 음성**으로 듣기. 음가 표기 정확성과 달리 합성 음가 소리는 완벽하지 않을 수 있음. 파닉스에서는 불필요한 '어' /ə/를 붙이지 않는 것이 중요하므로, 반드시 느린 단어 읽기와 부모/교사의 실제 음가 지도를 병행.
5. 소리 잇기: 각 단위를 차례로 강조한 후 전체 단어 느리게 재생. '천천히'와 '전체 읽기' 버튼 제공.
6. 마이크 따라 읽기: `SpeechRecognition`/ `webkitSpeechRecognition` 지원 여부 검사 후 사용자 클릭을 통해 한 단어만 인식. `en-US`, 최종 인식 대안 최대 5개 비교. 일치 여부만 확인하고 실패율/발음 정확도 수치 없음.
7. 인식이 잘 되지 않으면 다시 시도하고, 지원되지 않는 경우 보호자와 함께 확인 가능. 진행 카운트는 화면이 열려 있는 동안만 유지.

## 기술·사생활 보호 주의
- 마이크 버튼을 누르기 전에는 음성 인식을 실행하지 않음. 음성은 EDUNI 서버/DB/API로 전송하지 않고 파일로 기록하지 않음.
- 그러나 **브라우저의 음성 인식 공급업체**가 오디오를 서버로 전송할 수 있음(Chrome 포함). 단어 단위 연습 전에 부모의 허락과 네트워크 연결 필요.
- `getUserMedia`류 마이크 접근은 일반적으로 HTTPS/보안 컨텍스트를 필요로 하며, 내부 Tailscale HTTP 포털에서 제한될 수 있음. 이 경우 UI는 **HTTPS 공개 학습 페이지로 이동**을 안내하고 로컬 포털에서는 보호자 확인을 지원.
- 음성인식 모델이 어린이의 발음을 다른 단어로 듣는 경우가 있고, 짧은 단어의 동음이의어(sun/son, red/read, ten/10)도 있다. 판정은 **단어 인식 일치**이지 음소/억양 점수가 아님. 오인식 때문에 아이를 평가하거나 불이익 주지 않음.
- 발음 안내는 시스템 영어 음성의 품질에 따라 달라지므로, 향후 학습 전문가가 녹음한 음소별 오디오를 별도 라이선스 검토 후 추가하면 정확도를 높일 수 있음.
- 기타 서비스 데이터, 8080, 기존 수학·정글·게임 포털 경로는 변경하지 않음.
