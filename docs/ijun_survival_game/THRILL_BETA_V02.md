# 마주치지 마! 정글 대추격 — Beta v0.2

## 변경 동기
v0.1은 원숭이·뱀의 단순 왕복 이동을 피해서 출구까지 이동하면 끝나 긴장감과 도전 동기가 약했다. 의준이의 **목숨 1~35개 선택과 '마주치지 않고 살아남기'** 규칙은 그대로 유지한다.

## 새 플레이 흐름
1. 캐릭터, 목숨(1~35), **스릴(45초) / 여유(90초)** 선택
2. 정글 오른쪽의 **열쇠** 획득. 열쇠가 없으면 출구는 잠김
3. 열쇠를 얻는 순간 **재규어 추격** 시작. 상대 위치에 따라 HUD 경고 변화
4. 경고 원이 먼저 나타난 뒤 짧게 위험해지는 **떨어지는 열매 구역 2개**
5. PC 스페이스/Shift 또는 모바일 ⚡ 버튼으로 **0.5초 질주**, 사용 후 **5초 대기**
6. 타이머 종료 전에 출구에 도착하면 승리. 별은 선택 수집
7. 충돌 시 기존처럼 목숨 1개만 차감, 1.5초 중복 피격 방지

## 보완 사항
- 재규어 AI는 그저 플레이어 방향으로 직진하지 않으며 **24px 탐색 그리드 BFS 경로**를 0.85초마다 갱신한다. 기존 나무 장애물의 충돌 규칙은 그대로 적용한다.
- 전투·공포 대신 색상 경고, 짧은 화면 흔들림(모션 감소 사용자 설정 존중), 추격 배너와 질주 빛 효과를 사용한다.
- 게임 내 모든 실행 상태는 브라우저 메모리에서만 사용. 광고/계정/개인정보 업로드 없음.
- 게임 화면의 안내·입력은 모바일과 PC를 모두 고려한다.
- 원래 캐릭터 2종, 기존 정글 맵, 원숭이/뱀, 별, 이전 게임 경로는 유지한다.

## 검증 기록
- 새 게임 로직 JS 파일과 Node 형식 테스트 모듈을 V8 환경에서 분리 실행: **12개 검증 케이스 PASS**
- 장애물 뒤에서 출발한 재규어가 실제로 나무를 돌아 열쇠 위치에 도달하는 경로 검증 PASS
- 브라우저 DOM/Canvas 모의 환경: 설정→시작→잠긴 문→열쇠 획득/추격→모바일 질주→일시정지/재개→승리→재시작→45초 제한시간 패배→여유 모드 전환 PASS
- Pages 정적 HTML과 NiceGUI HTML의 스크립트 주소(버전 파라미터) 검증 PASS
- **남은 검증:** 실제 모바일 브라우저, 서버에서 실제 Python/Node 명령 실행, GitHub Pages HTTP 실접속 여부.

## 배포 및 인수
- `/survival/` GitHub Pages 베타 파일을 `main`에 업데이트해야 공개 베타에 반영.
- NiceGUI 가족 PC의 `/survival` 은 PC 코드 동기화/서버 재시작이 별도로 필요.
- 게시/병합 성공과 실서버 접근 성공을 혼동하지 말 것.
- 의준이가 3회 이상 플레이하며 난이도·재규어 속도·타이머 적합성을 검토할 것.
