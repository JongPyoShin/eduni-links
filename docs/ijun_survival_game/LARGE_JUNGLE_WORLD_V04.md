# 마주치지 마! 서바이벌 v0.4 — 정글 대탐험 월드 확대

## 목표
기존 EDUNI의 정글탐험(2D 게임: 2048×1152 맵과 카메라 이동)을 참고하여, 의준 서바이벌을 **스크롤되는 큰 정글 월드**로 확장한다. 서로 다른 게임의 문제풀이/도감 시스템은 섞지 않고, 서바이벌의 지속 추격·은신·열쇠·탈출 규칙을 유지한다.

## 구현 범위
- **월드 2048×1536**, 플레이 창은 기존 720×720 유지. 월드 면적 약 **6.07배** 확대.
- 플레이어를 부드럽게 따라가는 카메라, 화면 경계 고정, 모바일 방향키/WASD 입력 유지.
- 탐험 지역: 시작 야영지가 있는 **이끼길 입구**, **나비 숲**, **폭포 계곡**, **고대 유적**, 신비한 숲길과 꽃밭 쉼터 등 표지물.
- 숲길 커브, 폭포 웅덩이와 풀숲, 지역색과 경계 나무 등 캔버스 2D 정글 풍경. 네트워크 에셋이나 외부 의존성 없음.
- 오른쪽 위 고정 **미니맵**: 하얀 점 플레이어, 노란 점 다음 목표(열쇠→출구), 붉은 점 추격자, 은신처 표시, 카메라 현재 표시 영역.
- 상단 HUD: 현재 지역 이름과 목표까지의 대략적인 이동 거리.
- 시작점 (124,1325), 열쇠 (1685,938), 출구 (1890,144)로 분산, 별 5개와 은신처 8곳, 적 3종과 재규어, 과일 위험구역 4곳, 울창한 나무/장애물 14개.
- 정글이 커짐에 따라 제한시간 **스릴 105초 / 여유 180초**로 변경.
- AI 충돌 및 추적 경로 탐색 그리드를 27×27 고정값에서 월드 너비/높이에 맞춰 동적으로 구성. 추격자가 장애물 뒤에서 멈추지 않고 넓은 월드를 통과하도록 보완.
- 기존 숨기→몹 분산→시간제 은신처 소멸, 목숨 1~35, 질주·키·승리/실패, 조작·개인정보 기본값 유지.
- 정글탐험 게임 자체의 소스, 이미지, 경로는 변경하지 않음.

## 검증 수행
- 기존 규칙/확장 지도 관련 JS 테스트 21개: V8 실행환경에서 PASS.
- 새 시작점·출구·열쇠·은신처 8개·별 5개·위험구역·추적 목표·추격자 좌표가 모두 유효한지 확인.
- 시작점→열쇠→출구까지 24px BFS 경로 존재, 넓은 정글 안에서 몬스터 추적 가능 여부 확인.
- DOM/Canvas 모의 브라우저: 방향키 이동 시 카메라 실제 이동, 지역별 카메라 경계, 은신처 타이머, 열쇠 획득·재규어·탈출, 재시작 시 맵 복원 PASS.
- Pages HTML과 NiceGUI 서버 HTML은 스크립트 경로 이외에는 일치하며 `?v=4` 캐시 버전 적용.
- **미검증**: 실제 모바일 화면 터치와 FPS, Node/Python 전체 테스트 CLI 실행, Pages HTTP 배포와 가족 PC 업데이트.

## 공개 정책
개발 브랜치에서 Draft PR로 보관하고 실제 사용자 배포는 별도 승인 후 진행. 공개 v0.3.1의 경로와 구동 게임을 자동으로 덮어쓰지 않는다.
