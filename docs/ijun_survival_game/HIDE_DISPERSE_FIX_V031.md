# 의준 서바이벌 v0.3.1 — 은신처 앞 몬스터 대기 현상 개선

## 발생 상황
v0.3에서 숨은 중 몬스터 목표가 은신처와 약 46~65px 떨어진 곳으로 설정되었다. 은신처가 사라지면 몬스터가 바로 플레이어를 다시 쫓아오는 결과가 발생했다.

## 변경
- 숨기 활성화 즉시 기존 적과 재규어의 추적 목적지를 **은신처에서 210px 이상 먼 서로 다른 탐색 지역**으로 전환한다.
- 게임 월드 내 이동 가능한 고정 8개 후보 지역에서 은신처와 충분히 먼 4곳을 선택한다. 몬스터마다 개별 지역을 배정해 한자리에 모이지 않도록 한다.
- 기존 BFS 장애물 길찾기를 유지하면서 몬스터를 해당 먼 지역으로 실제 이동시킨다. 몬스터 순간이동은 사용하지 않는다.
- 은신처 제한시간이 끝나거나 플레이어가 일찍 나와도 **2.8초간 다른 곳 수색**을 계속하고, 그 뒤 일반 추격으로 복귀한다.
- 숨은 직후 1.3초 피격 보호, 짧은 탈출 가속, 1회용 은신처 규칙은 유지한다.
- 화면 설명과 위험 HUD 표시를 실제 바뀐 몬스터 동작에 맞춰 수정한다. Pages와 가족서버용 HTML에 동일한 `?v=31` 스크립트 버전 사용(캐시 갱신).
- 기존 정글 맵, 목숨 1~35, 열쇠, 시간제 은신, 출구, 질주 등은 변경하지 않음.

## 검증
- JS 순수 규칙 18개 V8 격리 실행 PASS. **모든 은신처 위치**에서 각 몬스터의 목적지가 210px 이상 멀고 서로 다르며, 제한시간 종료 시 160px 이상 떨어지는 회귀테스트 추가.
- 실제 게임 코드 DOM/Canvas 모의 플레이: 숨기→몬스터 분산→4초 후 장소 소멸→몬스터가 멀리 있음→2.8초 추가 수색→일시정지/재개→열쇠/탈출 PASS.
- 덤불 4초 후 모의 플레이 몬스터 3마리 이격 거리 369/535/512px.
- 가족서버 HTML과 정적 Pages HTML 일치 확인.
- 남은 검증: 실제 브라우저·휴대폰 플레이, Node CLI 전체 실행, Python 회귀 전체 및 실제 Pages HTTP 응답 확인.
- GitHub Pages의 공개 버전은 `main` 병합 후 게시되며, 가족 PC NiceGUI 서버는 별도 코드 동기화/재시작이 필요하다.
